# Vita Guía v2.0.0

Interfaz móvil sobre el sistema existente. Mantiene la paleta verde, menta, coral y papel, los datos y los permisos actuales.

- Navegación inferior y tareas separadas para cliente, usuario y administrador.
- Panel, enlaces, usuarios, contenido y revisiones con destinos propios; acceso visible entre página y panel, y cierre de sesión.
- Productos con información progresiva y chat a pantalla completa conservando el producto y la visita del cliente.
- Editores móviles para videos subidos, enlaces externos, historias y documentos.
- Aportaciones con detalles, archivos, vista previa y decisión administrativa; cambios y reenvío sin publicación automática.
- Documentos con archivo, versiones, texto, productos, acceso y revisión. Consulta interna exclusiva del administrador.
